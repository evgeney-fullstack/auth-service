# Auth Service

Микросервис аутентификации и регистрации пользователей с использованием JWT и PostgreSQL.

## Описание

`auth-service` — это микросервис, отвечающий за:
* регистрацию новых пользователей;
* аутентификацию (логин) пользователей;
* генерацию и валидацию JWT‑токенов;
* управление refresh‑токенами (с хранением в БД);
* проверку подлинности JWT‑токенов для защищённых эндпоинтов.

Сервис разработан на языке Go с использованием PostgreSQL в качестве основного хранилища данных.

## Технологии

* **Язык программирования:** Go (Golang) 1.21+
* **База данных:** PostgreSQL 14+
* **Аутентификация:** JWT (JSON Web Tokens)
* **Хеширование паролей:** bcrypt
* **HTTP‑фреймворк:** net/http + gorilla/mux (или аналогичный)
* **Миграции БД:** golang-migrate/migrate
* **Конфигурация:** YAML/JSON
* **Сборка и запуск:** Docker + docker-compose

## Функциональные возможности

* Регистрация пользователя по email и паролю.
* Аутентификация пользователя (логин), выдача JWT‑токена.
* Обновление JWT‑токена с использованием refresh‑токена.
* Валидация JWT‑токенов для доступа к защищённым ресурсам.
* Безопасное хранение паролей (хеширование с bcrypt).
* Хранение refresh‑токенов в PostgreSQL для возможности отзыва.
